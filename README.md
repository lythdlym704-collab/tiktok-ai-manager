# TikTok AI Manager — Android

تطبيق Android أصلي لإعداد قصص عربية قصيرة، إنشاء قصتين يومياً من مولّد محلي تركيبي، تقسيم النص إلى مقاطع مشهدية، وتشغيل التعليق عبر Android TextToSpeech.

## ما يعمل في هذا الإصدار
- إنشاء قصتين يومياً وتخزينهما محلياً لمنع إعادة توليد القصتين نفسيهما في اليوم نفسه.
- سجل تركيبات سابقة لتقليل تكرار النصوص.
- تقسيم النص إلى مشاهد نصية.
- نطق عربي عبر محرك TTS المثبت على الهاتف.
- حفظ المسودة ونسخ النص.

## ما لم يُفعّل بعد
- المولّد الحالي محلي قائم على تراكيب نصية، وليس نموذج ذكاء اصطناعي متصلاً بالإنترنت.
- صوت TTS صوت اصطناعي من محرك الهاتف وليس تسجيلاً بشرياً.
- لا يوجد حالياً تصدير فيديو MP4 أو إخراج 4K أو توليد لقطات فيديو/موسيقى.
- لا يوجد تسجيل دخول TikTok مكتمل أو نشر تلقائي. زر TikTok يفتح بوابة المطورين فقط.

## متطلبات TikTok الرسمية
يلزم تسجيل تطبيق في TikTok for Developers، تفعيل Login Kit وContent Posting API، إضافة بيانات التطبيق وRedirect URI وبصمة توقيع Android. النشر المباشر يحتاج موافقة صلاحية video.publish ومراجعة التطبيق. يجب تبادل رموز OAuth وحفظ الأسرار ورموز التحديث على خادم آمن، وعدم وضع client_secret داخل APK.
